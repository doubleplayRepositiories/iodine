# Iodine

A fast, minimalist, and highly customizable unblocked platform built to bypass network restrictions seamlessly.

## Features

- **Instant Loading:** Lightweight codebase ensures games load without lag.
- **Tab Cloaking:** Disguises the site as Google Docs or Canvas with one click.
- **Clean UI:** No intrusive pop-ups, trackers, or heavy ad scripts.
- **Massive Catalog:** Access to hundreds of HTML5, Flash (via Ruffle), WebGL games, music, shows, tv, and a chatroom.
- **Anti-Detection:** Built-in proxy support to evade standard school and workplace firewalls.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Emulation:** Ruffle (Flash Player emulation)
- **Game CDN:** jsDelivr (Distributed asset delivery)

## Getting Started

### Local Deployment

1. Clone the repository:
```bash
git clone https://github.com
```

2. Navigate to the project directory:
```bash
cd iodine
```

3. Open `index.html` directly in your browser, or spin up a local server:
```bash
python -m http.server 8080
```

## Game Requests & Suggestions

If you want to suggest a new game, please open an issue with the following details:
- Game Title
- Link to source code or original game URL
- Suggested categories

*Note: Pull requests adding external host links, magnet links, or unauthorized distribution endpoints will be closed immediately to maintain site safety and security.*
